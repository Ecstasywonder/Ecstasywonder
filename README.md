## Working principles

I try to make engineering decisions visible in the repository: architecture notes, deployment boundaries, security assumptions, CI checks, tests, runbooks and known production gaps. A project is more useful to me when another engineer can understand **how it works, how it is verified, how it is deployed and what still needs to be improved**.
