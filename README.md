## Stack

This version is intentionally lightweight and deployable without a framework:

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- Responsive layout
- Accessible navigation
- Reduced-motion support
- Scroll reveal and reading progress interactions

## Run locally

Because this is a static site, any local static server works. For example:

    python -m http.server 8000

Then open http://localhost:8000.

## Deployment

The repository can be deployed directly to GitHub Pages, Vercel or any static hosting provider.

## Design direction

The visual system uses a restrained dark interface, high-contrast typography, mono technical labels, subtle motion and generous spacing. The goal is to feel like an engineering portfolio rather than a generic template.
